# Command 'juju reload-spaces'

```{caution}

The information in this doc is based on Juju version 3.5.5,
and may not accurately reflect other versions of Juju.

```

> See also: {ref}`spaces <command-juju-spaces>`, {ref}`add-space <command-juju-add-space>`, {ref}`show-space <command-juju-show-space>`, {ref}`move-to-space <command-juju-move-to-space>`

## Summary
Reloads spaces and subnets from substrate.

### Options
| Flag | Default | Usage |
| --- | --- | --- |
| `-B`, `--no-browser-login` | false | Do not use web browser for authentication |
| `-m`, `--model` |  | Model to operate in. Accepts [&lt;controller name&gt;:]&lt;model name&gt;&#x7c;&lt;model UUID&gt; |

## Examples

	juju reload-spaces


## Details
Reloades spaces and subnets from substrate.
