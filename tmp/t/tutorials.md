# Tutorials

End-to-end tutorial covering different aspects of COS for new users.

# Installation and Deployment
Get COS up and running on your MicroK8s environment with ease. This tutorial walks you through the steps required to deploy the COS Lite bundle, a Juju-based observability stack running on Kubernetes.
- {ref}`Getting started on MicroK8s <getting-started-on-microk8s>`

# Configuration
In this tutorial you will learn how to make COS Lite automatically sync the alert rules of your git repo to Prometheus using the [COS Configuration charm](https://charmhub.io/cos-configuration-k8s/docs).
- {ref}`Sync alert rules from Git <sync-alert-rules-from-a-git-repo-using-the-cos-configuration-charm>`

# Instrumentation
Bridge the gap between COS Lite running in Kubernetes and your application running on a machine. Discover how to collect telemetry data from your charmed application using the Grafana Agent machine charm.
- {ref}`Instrumenting machine charms <using-the-grafana-agent-machine-charm>`
