**[Canonical Observability Stack Lite](https://charmhub.io/cos-lite)** (COS Lite) is designed for the Edge and is capable of running reliably alongside MicroK8s and Juju with limited computing resources (around 8 GB of memory).

The charms in COS Lite can be integrated with other Juju-managed applications to provide a turn-key observability solution for your charmed workloads.
You can however also use the [Grafana Agent](https://charmhub.io/grafana-agent-k8s) to set up COS Lite to monitor your applications even if they're not charmed: [see how](/t/12005).

## Components

The charmed operators that make up COS are available as the pre-configured [COS Lite](https://charmhub.io/cos-lite) bundle. COS Lite is made up of the following Juju charmed operators:

| Charms |
| -- |
| https://charmhub.io/prometheus-k8s |
| https://charmhub.io/alertmanager-k8s |
| https://charmhub.io/loki-k8s |
| https://charmhub.io/grafana-k8s |
| https://charmhub.io/traefik-k8s |
| https://charmhub.io/catalogue-k8s |

Additionally, there are charmed operators designed to work with COS to provide additional functionality:

| Charms |
| -- |
| https://charmhub.io/prometheus-scrape-config-k8s |
| https://charmhub.io/prometheus-scrape-target-k8s |
| https://charmhub.io/cos-proxy |
| https://charmhub.io/cos-configuration-k8s |
| https://charmhub.io/karma-k8s |
| https://charmhub.io/grafana-agent-k8s |

- The [Prometheus Scrape Config](https://charmhub.io/prometheus-scrape-config-k8s) charmed operator allows you to ** tweak the settings of the scrape jobs** when relating a charm to the [Prometheus](https://charmhub.io/prometheus-k8s) charmed operator.

- The [Prometheus Scrape Target](https://charmhub.io/prometheus-scrape-target-k8s) charmed operator allows you to represent `/metrics` endpoints provided by software not managed by Juju, e.g., [LXD](https://linuxcontainers.org/lxd/docs/master/metrics) or [MaaS](https://maas.io/docs/prometheus-metrics), so that the [Prometheus](https://charmhub.io/prometheus-k8s) charmed operator can scrape metrics from them.

- The [COS Proxy](https://charmhub.io/cos-proxy) charmed operator is a [machine charm](https://juju.is/docs/sdk) designed to **“translate” the relations** supported by the previous iteration, LMA, to COS.

- The [COS Configuration](https://charmhub.io/cos-configuration-k8s) charmed operator provides a GitOps approach to manage Prometheus alerts, Loki alerts and Grafana dashboards that are specific to your Juju deployments, rather than any particular charm.

- The [Karma](https://charmhub.io/karma-k8s) charmed operator runs the [Karma UI](https://karma-dashboard.io/) for you on kubernetes, which enables you to visualize alerts from various Alertmanager clusters, e.g., when you were to deploy many different COS on Edge computing on in different production environments, and wanted to keep a centralized overview.

- The [Grafana Agent](https://charmhub.io/grafana-agent-k8s) charmed operator provides a way to fetch and forward telemetry and dashboards via cross-model relations and from remote workloads, and send them over to the observability stack.
