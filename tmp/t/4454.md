> See also: [How to set up a charm project](/t/5547)

Below is a list of the files you may encounter in a charm project. This includes:
- files created automatically for you when you set up a charm project with `charmcraft init` (e.g., all the 3 crucial files -- [`charmcraft.yaml`](/t/7132), [`requirements.txt`](/t/7148), and [`src/charm.py`](/t/7150) -- but not just; you'll likely want to edit all)
- files created automatically for you when you pack a charm with `charmcraft pack` (e.g., [`actions.yaml`](/t/7131), [`config.yaml`](/t/7133), [`dispatch`](/t/12676),  [`manifest.yaml`](/t/7154), [`metadata.yaml`](/t/5213))
- files you may want to add on your own (e.g., [`icon.svg`](/t/7153), [`lxd-profile.yaml`](/t/4453)).
