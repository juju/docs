> See also: [How to manage action tasks](/t/1033#heading--manage-action-tasks)

In Juju, a **task** is the execution of an [action](/t/6208) (via [`juju run`](/t/1803)) or of other arbitrary scripts (via [`juju exec`](/t/6344)) on a target [unit](/t/5460). 

Action tasks are run as defined by the charm author (default: sequentially), whereas tasks related to other scripts are run as set by the charm user (default: parallel).

A group of tasks queued by running an action across one or more units forms an [operation](/t/7934).
