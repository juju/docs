> See also: [How to manage the client](/t/1083)

A Juju **client** is any software that implements the Juju client apiserver contract. 

This currently includes:

- the Juju CLI ([`juju`](/t/5465))
- the Terraform CLI when used with the `juju` provider plug-in ([`terraform juju`](/t/13086))
- the `python-libjuju` library ([`python-libjuju`](/t/13089))
