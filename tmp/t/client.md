# Client

> See also: {ref}`How to manage the client <how-to-install-and-manage-the-client>`

A Juju **client** is any software that implements the Juju client apiserver contract. 

This currently includes:

- the Juju CLI ({ref}``juju` <juju-juju-client>`)
- the Terraform CLI when used with the `juju` provider plug-in ({ref}``terraform juju` <terraform-juju-juju-client>`)
- the `python-libjuju` library ({ref}``python-libjuju` <python-libjuju-juju-client>`)
